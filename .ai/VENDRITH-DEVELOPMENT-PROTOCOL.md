# Vendrith Development Protocol v1

This is a Vendrith-specific adaptation of ECC engineering principles, not a wholesale ECC installation.

## Level 0
Simple documentation/style changes: REQUEST -> IMPLEMENT -> VERIFY

## Level 1
Normal features: REQUEST -> RESEARCH (if needed) -> PLAN -> IMPLEMENT -> TEST -> REVIEW -> VERIFY

## Level 2
Architectural features: REQUEST -> ONBOARDING -> RESEARCH -> PLANNER -> ARCHITECT -> SPECIALIST -> IMPLEMENT -> TEST -> CODE REVIEW -> SECURITY REVIEW -> VERIFY -> DOCUMENT

## Level 3
Critical systems: REQUEST -> ONBOARDING -> RESEARCH -> ARCHITECTURE -> SECURITY REVIEW -> PLAN -> IMPLEMENT -> TEST -> CODE REVIEW -> SECURITY REVIEW -> BUILD -> BROWSER VERIFY -> FINAL REVIEW

## Specialist routing
Map editor: map-editor-specialist
PixiJS: pixijs-specialist
Game data: game-data-specialist
Assets: asset-pipeline-specialist
Supabase: supabase-specialist
Vercel/Next.js: vercel-specialist
Architecture: vendrith-architect

Never report completion until the appropriate verification passes or the remaining failure is explicitly documented.
