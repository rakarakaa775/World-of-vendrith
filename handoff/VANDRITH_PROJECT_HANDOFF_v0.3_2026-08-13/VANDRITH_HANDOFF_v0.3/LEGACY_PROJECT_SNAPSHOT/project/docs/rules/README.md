## How To Use

1. **Before starting any task**, read the Rule Books relevant to your work. At minimum, read `01_Project_Rules.md` and `08_Naming_Rules.md`.
2. **AI assistants** must additionally read `docs/ai/` working memory before starting, per `07_AI_Rules.md`.
3. **Every change** must be consistent with all eight Rule Books. No exceptions.
4. **New rules** are added to the relevant Rule Book, not invented ad hoc. A new domain gets a new numbered file, added here to the index.

All eight Rule Books are complete and locked as part of Foundation v1.0.
