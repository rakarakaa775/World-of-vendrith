# Asset Checklist

> The Vendrith World — checklist every asset must pass before integration.

## 1. Origin
- [ ] Source identified (commissioned, stock, generated, in-house).
- [ ] License verified and compatible with the project.
- [ ] Credit/attribution recorded if required.

## 2. Quality
- [ ] Resolution and format meet project standards.
- [ ] No artifacts, compression damage, or visible errors.
- [ ] Consistent with the style guide (`Asset_Style_Guide.md`).

## 3. Naming
- [ ] Filename is `snake_case`.
- [ ] Name describes content, not author or date.
- [ ] No spaces, special characters, or version numbers.

## 4. Placement
- [ ] Asset moved to the correct folder (`core/`, `expansions/`, or `generated/`).
- [ ] Removed from `inbox/`.

## 5. Registration
- [ ] Asset registered in `src/assets/registry/` with metadata.
- [ ] Metadata includes: name, type, source, license, folder, tags.

## 6. Final
- [ ] Reviewed by the Lead Architect or designated reviewer.
- [ ] Approved for integration.
