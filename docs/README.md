# Documentation Structure

- `audits/` — current audit and verification records.
- `architecture/` — current architecture and engine contracts.
- `handoff/` — project handoff material and historical continuity documents.
- `database/` — database specifications, migrations, validation, and reconciliation records.
- `assets/` — asset manifests and provenance documentation.
- `archive/` — packaged historical snapshots that are intentionally retained.

Historical handoff material is retained rather than mixed into the current implementation directories.
