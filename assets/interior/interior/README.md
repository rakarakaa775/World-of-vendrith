# INTERIOR BINARY STAGING

This directory is the imported interior binary checkpoint.

INTERIOR roles are floors, walls, ceilings, doors/windows, stairs, furniture, decoration props, interactables, crafting stations, lighting and dungeon interiors.

Interior assets are map-role bindings, not a reason to duplicate the canonical object/source library. Preserve source identity, license and attribution during reconciliation.

Do not glob-import this directory.
