# WORLD BINARY STAGING

This directory is a binary import/staging checkpoint, not an unrestricted canonical WORLD library.

Only natural environment assets may receive a final WORLD role: terrain, water, mountains, hills, cliffs, natural rock formations, forests, jungle, desert, swamp, snow/ice and natural vegetation.

Character, animal, clothing, weapon, vehicle, animation and man-made structure assets found in the imported package remain preserved here until reconciled to their canonical libraries. Do not glob-import this directory into the World Builder.

See `assets/_documentation/BINARY_ASSET_RECONCILIATION_2026-09-26.md`.
