# REGION BINARY STAGING

This directory is a binary/map-authoring import checkpoint.

REGION is a map-role classification for roads, paths, bridges, docks, ports, villages, towns, cities, castles, fortifications, ruins, farms, camps and regional context. TMX/TSX files are authoring resources and are not automatically approved asset records.

Do not glob-import this directory into runtime or the World Builder. Final asset identity, provenance and map-role bindings must be reconciled first.
