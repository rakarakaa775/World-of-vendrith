# REGION Assets

REGION stores the exterior, man-made structures and static locations used by the Vandrith World Builder.

Canonical map role:

- roads and paths
- bridges
- docks and ports
- static ships/boats
- villages, towns and cities
- castles and fortifications
- ruins
- farms and camps
- regional decorative props

Gameplay-interactive assets remain in their dedicated gameplay systems. Natural terrain belongs to WORLD. Interior environment belongs to INTERIOR. Living entities belong to LIFE_GENERATION.

See `assets/_documentation/REGION_ASSET_AUDIT.md` for the complete classification and provenance rules.
